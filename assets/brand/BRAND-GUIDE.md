# GoBilling Logo Asset Guide

## Primary identity

- The core mark is the gold geometric **G** with the central four-point sparkle and rectangular terminal.
- The official name is written **GoBilling** with capital **G** and **B**.
- Primary colours: Emerald `#092A20`, Gold `#B9892E`, Light Gold `#E7C77E`, Ivory `#FFFCF5`.

## Which file to use

- Website header on a light background: `website/gobilling-wordmark-dark-720.png`
- Website header on a dark background: `website/gobilling-wordmark-light-720.png`
- High-density/large website placement: use the `1440` wordmark variant.
- Windows executable: `application/gobilling-app.ico`
- Windows installer/store listing: `application/gobilling-app-icon-512.png` or `1024.png`
- Browser favicon: `website/favicon.ico`
- Apple touch icon: `website/apple-touch-icon.png`
- PWA/Android: `website/pwa-icon-192.png` and `website/pwa-icon-512.png`
- Social sharing: `website/gobilling-social-preview.png`
- Transparent standalone mark: `application/gobilling-transparent-mark-512.png`
- Source-quality artwork: files inside `masters/`

## Clear space and minimum size

- Keep empty space around the logo equal to at least half the height of the central sparkle.
- Do not use the full wordmark below 140 pixels wide; use the standalone mark instead.
- Do not recolour, stretch, rotate, outline, crop, or place the logo over a busy image.
- Use the dark wordmark on ivory/light backgrounds and the light wordmark on emerald/black backgrounds.

## Important production note

These masters are high-resolution transparent PNG artwork. For very large physical signage, embroidery, engraving, or trademark filing, commission a manual vector trace from the approved master rather than using an automated trace.
